Links should Contain Descriptive Text

The “Links should Contain Descriptive Text” states that all links and hyperlinks should have meaningful, standalone text accompanying it. When navigating through pages, sceen readers generate a list of all the links on a page. Multiple links containing random symbols, numbers, or characters can confuse users.
