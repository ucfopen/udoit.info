Images Should Have Alternative Text

The “Images Should Have Alternative Text” states that images that convey important information should contain a text alternative with the same information.

This alternative text will make the information accessible to users with assistive technologies. However, if an image is just decorative, it should be indicated as such.

To resolve this error:

To fix this error, use the widget to add an “alt” attribute to the image, and create a short description of what is being described. You can also use an aria-label. Be sure to include any important words displayed on the image.

Alternatively, you can add the “presentation” role to images that are not being used to relay information.
