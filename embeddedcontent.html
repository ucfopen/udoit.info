Embedded Content Should Have a Label

The “Embedded Content Should Have a Label” error indicates embedded content was found without a descriptive title or label.

A frame, video, or image should have a unique, descriptive title so students using a screen reader can quickly read the context and decide if they wish to navigate there, like a sign on a door.

To fix this error, use the widget to add a descriptive label to the title attribute within the embedded element.
