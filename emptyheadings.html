Headings Should not be Empty

The “Headings Should not be Empty” error references heading elements that contain no text. A heading element is any text that is programmatically wrapped with an < h1 >,< h2 >,< h3 >, tag, and so on.

Users who are blind or using screen readers rely on properly structured headings so they can quickly understand the page contents.

To fix this error, avoid skipping heading levels and ensure all headers contain text. Use the widget to add a descriptive header, or remove the header element altogether.
