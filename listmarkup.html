Lists should have Proper List Markup

The “Lists should have Proper List Markup” error states that lists must be properly, programmatically formatted so that users with assistive technologies can navigate and understand the content within the list.

This means it is not enough to type an asterisk, dash, or numbers to indicate a list. The easiest way to create a properly formatted list is through using the list tool inside of your content editor. Each list should be defined as ordered or unordered, and each element within the list should be defined as a list item.

This error cannot be fixed within UDOIT, but lists can be edited and created within the Canvas text editor.

To resolve this error:

ensure your list is created as an HTML list, and defined as either an ordered list, using <ol> tags, or an unordered list, using <ul> tags. Then, confirm that the list items are sufficiently defined as such, using proper <li> tags around each item.
