Walkthrough & Tutorials

We understand that UDOIT may be a learning curve, but we aim to make it as user-friendly as possible. Below are some tutorials addressing common hurdles when users first begin using UDOIT, as well as tutorials which address fixing specific errors that UDOIT scans for.

More Tutorials

  • Blockquotes Must Have a Citation

    This error indicates a section that was quoted from another source does not contain its necessary citation.

  • Embedded Content Should Have a Label

    This error indicates embedded content was found without a descriptive title or label.

  • Information Should not be Conveyed by Colour Alone

    This error says that color by itself should not be used to present information or convey importance.

  • Lists Should Have Proper List Markup

    Lists must be properly, programmatically formatted so that users with assistive technologies can navigate.

  • Unable to Fix Inside of UDOIT

    If an error is within this category, there will not be a widget to assist you in solving the error.
