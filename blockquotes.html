Blockquotes Must Have a Citation

The "Blockquotes Must Have a Citation" error indicates a section that was quoted from another source does not contain its necessary citation.

Blockquote elements tell assistive technologies which content is part of a quote or citation from another source. This means that using the blockquote element for indentation or formatting purposes is strongly dissuaded, as it can mislead assistive technology.

To fix this violation, verify the blockquote is actually being used for a quote, and contains the necessary “cite” attribute. Or, use the widget to add the proper citation to the quote, or remove it altogether if necessary.
